## Definido na reunião

1. [[#Cronograma | Cronograma]]
2. Passar a tarefa da Apresentação para o Departamento de Comunicação
	-> Fazer o PowerPoint 
	-> Fazer as "falas" 
3. Escolher as pessoas que vão fazer a apresentação do NECC
4. Passar a tarefa das dinâmicas do GPS para o recreativo
	-> Definir o bingo, fazer as cartelas 
	-> A atividade de esconder as imagens nos lugares do GPS 
	-> Criarem, se possível,  novas "brincadeiras"
	-> Pensar como seriam os pontos para cada brincadeira 
5. Definir o que seria o "prémio" da equipa vencedora das dinâmicas do GPS
	* Uma idea era o prémio ser algo relacionado já com o piquenique, assim eles eram meio que obrigados a ir ao piquenique*
	* Isso também pode ser atribuido ao dep. recreativo
6. Sabendo as pessoas que temos certas como embaixadores, pensar em quantos grupos vamos dividir os caloiros e quantos "guias" vão ter por grupo
	-> Se possível, já dividir os embaixadores em grupos e pré-definir uma rota para esses guias; 
	Para evitar que os grupos se cruzem no caminho, ou entrem em um mesmo ambiente ao mesmo tempo.
7. Organizar o piquenique 
	 * O dia para o piquenique ainda é incerto;
	 -> Orçamento para os lanches
	 -> O que vai ser comprado 
	 -> Quem fica responsável de comprar os lanches
	 -> Quantas pessoas temos para ir no dia 11 para o piquenique
	 -> Que tipos de jogos podemos levar 
	 -> O que mais se pode fazer com os caloiros durante o piquenique
