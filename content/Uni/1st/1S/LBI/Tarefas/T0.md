```hs title:dimensaoMatriz
dimensaoMatriz :: Matriz a -> Dimensao
```

 ## Exercício 5 
Versão da função `movePosicao` que garante que o movimento não se desloca para fora de uma janela.

**NB:** Considere uma janela retangular com origem no canto superior esquerdo definida como uma matriz. A função recebe a dimensão da janela.

```hs title:ePosicaoDimencaoValida
ePosicaoDimencaoValida :: Posicao -> Dimensao -> Bool
ePosicaoDimencaoValida (x, y) (dx, dy) =  x >= 0 && x <= dx && y >= 0 && y <= dy
```

```hs title:movePosicaoJanela
movePosicaoJanela di d p = if  ePosicaoDimencaoValida (pfx, pfy) di

                        else p
                    where (pfx, pfy) = movePosicao d p
```

```hs title:centroJanela
centroJanela :: Dimensao -> Posicao
```

# Funções Recursivas 

## Exercício 1
Devolve o elemento num dado índice de uma lista.

**NB:** Retorna `Nothing` se o índice não existir.

```hs title:encontraIndiceLista
encontraIndiceLista :: Int -> [a] -> Maybe a
encontraIndiceLista a lista | length lista < a + 1  = Nothing
                            | otherwise = Just ( lista !! a )
```

## Exercício 2
Modifica um elemento num dado índice.

**NB:** Devolve a própria lista se o elemento não existir.
```hs title:atualizaIndiceLista
atualizaIndiceLista :: Int -> a -> [a] -> [a]
atualizaIndiceLista i x l = if i > length l 
                            then l 
                            else l1 ++[x]++ tail l2
                                where (l1 ,l2) = splitAt i l 
```

## Exercício 3
Devolve o elemento numa dada posição de uma matriz.

**NB:** Retorna `Nothing` se a posição não existir.

_A numa matriz não existe posição 0, por isso subtraio 1 
do x e do y, respectivamente, referentes a linha e a coluna da matriz
para quando usar o !! dá o elemento da posição desejada
Argumento descartado já que sim, pode ser 0 a coordenada de um elemento
de uma matriz._ 

```hs title:encontraPosicaoMatriz
encontraPosicaoMatriz :: Posicao -> Matriz a -> Maybe a
encontraPosicaoMatriz _ [] = Nothing 
encontraPosicaoMatriz (x,y) m = if ePosicaoDimencaoValida (x,y) (l,c)
                                then Just ((m !! x)!!y)
                                else Nothing
              where (l,c) = dimensaoMatriz m
```

```hs title:atualizaPosicaoMatriz
atualizaPosicaoMatriz :: Posicao -> a -> Matriz a -> Matriz a
atualizaPosicaoMatriz (x,y) a m = if ePosicaoDimencaoValida (x,y) (l,c)
                                 then m1 ++ [mf1]++(tail m2)
                                 else m
```

## Exercício 5 
Aplica uma sequência de movimentações a uma posição, pela ordem em que ocorrem na lista.

- Função  *Auxiliar* que soma os deslocamentos de uma lista de direções 
```hs title:
somaDeslocamentodirecao :: [Direcao] -> Posicao
somaDeslocamentodirecao [] = (0,0)
somaDeslocamentodirecao [x] = deslocamento x
somaDeslocamentodirecao (h:t) = let (x1,y1) = deslocamento h 
                                    (x2,y2) = somaDeslocamentodirecao t 
                                in (x1 + x2 , y1 + y2) 
```

- Função principal 

```hs title:moveDirecoesPosicao
moveDirecoesPosicao :: [Direcao] -> Posicao -> Posicao
moveDirecoesPosicao [] x = x
moveDirecoesPosicao [a] x = movePosicao a x
moveDirecoesPosicao (h:t) (x,y) = (x +x1 + a ,y + y1 + b )
                          where (x1, y1) = somaDeslocamentodirecao [h]
                                (a,b) = somaDeslocamentodirecao t 
```

## Exercício 7
Verifica se uma matriz é válida, no sentido em que modela um retângulo.

**NB:** Todas as linhas devem ter o mesmo número de colunas.

- Função auxiliar que vai comparar os length de cada linha da matriz 
```hs title:listaElementosIguais
listaElementosIguais :: Eq a =>  [a] -> Bool
listaElementosIguais [x,y] = x == y 
listaElementosIguais (x:y:t) =  x == y && listaElementosIguais (y:t)  
```
- Função Principal
```hs title:eMatrizValida
-- Não faria sentido verificar se uma matriz vazia é válida
eMatrizValida :: Matriz a -> Bool
eMatrizValida [x] = True
eMatrizValida m | listaElementosIguais (map length m) = True 
                | otherwise = False
```
