## Exercício 1 
Usando as seguintes funções pré-definidas do Haskell:
-  `length l`: o número de elementos da lista 
-  `head l`: a cabeça da lista (não vazia) 
-  `tail l`: a cauda da lista (não vazia) l 
-  `last l`: o último elemento da lista (não vazia) l

Defina as seguintes funções e os respectivos tipos:

### Alinha f)
`max2`– que calcula o maior de dois números inteiros.

> Dados dois números inteiros a função tem como output aquele número que será o maior


### Alinha g)

```hs title:max3
max3 x y z = max2 z (max2 x y)
```

## Exercício 2
Defina as seguintes funções sobre polinómios de 2º grau:

### Alinha a)
A função `nRaizes` que recebe os (3) coeficientes de um polinómio de 2º grau e que calcula o número de raízes (reais) desse polinómio.

```hs title:
nRaizes :: Double -> Double -> Double -> Double
nRaizes a b c | delta > 0 = 2
              | delta < 0 = 1
              | otherwise = 0
    where delta = sqrt (b^2 - (4 * a* c)) 
```

### Alinha b) 
A função `raizes` que, usando a função anterior, recebe os coeficientes do polinómio e calcula a lista das suas raízes reais.

```hs title:raizes
raizes :: Double -> Double -> Double -> [Double]
raizes a b c | nRaizes a b c == 0 = []
             | nRaizes a b c > 0 = [x1, x2]
             | otherwise = [x1]
    where  x1 = (-b + nRaizes a b c)/ (2 *a)
           x2 =  (-b - nRaizes a b c)/ (2*a)
```

### Alinha c)
Complete a seguinte definição cujo objetivo é calcular a área de uma figura:
```hs 
area :: Figura-> Double 
area (Triangulo p1 p2 p3) =
	let a = dist p1 p2 
		b = dist p2 p3 
		c = dist p3 p1 
		s = (a+b+c) / 2 -- semi-perimetro 
	in sqrt (s*(s-a)*(s-b)*(s-c))-- formula de Heron
```

```hs title:Solução
area :: Figura -> Double
area (Triangulo p1 p2 p3) =
                    let a = dist (polarParaCartesiano p1) (polarParaCartesiano p2)
                        b = dist (polarParaCartesiano p2) (polarParaCartesiano p3)
                        c = dist (polarParaCartesiano p3) (polarParaCartesiano p1)
                        s = (a+b+c) / 2 -- semi-perimetro
                    in sqrt (s*(s-a)*(s-b)*(s-c)) -- formula de Heron
area (Circulo p1 r) = 3.14*(r)^ 2
area (Rectangulo p1 p2) = 
               let p3 = Cartesiano x1 y2
                   a = dist (polarParaCartesiano p1) (polarParaCartesiano p2)
                   b = dist (polarParaCartesiano p2) (polarParaCartesiano p3)
                   c = dist (polarParaCartesiano p3) (polarParaCartesiano p1)
                   s = (a+b+c) / 2 -- semi-perimetro
                   metadeArea = sqrt (s*(s-a)*(s-b)*(s-c)) -- formula de Heron
                    in 2*metadeArea
             where (Cartesiano x1 y1) = polarParaCartesiano' p1
                   (Cartesiano x2 y2) = polarParaCartesiano' p2
```
