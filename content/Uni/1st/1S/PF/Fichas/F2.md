## Exercício 1 

Indique como é que o interpretador de Haskell avalia as expressões das alíneas que se seguem, apresentando a cadeia de redução de cada uma dessas expressões (i.e., os vários passos intermédios até se chegar ao valor final).

### Alinha a)
Considere a seguinte definição: 
```hs 
funA :: [Double]-> Double 
funA [] = 0 
funA (y:ys) = y^2 + (funA ys)
```
 Diga, justificando, qual é o valor de `funA [2,3,5,1]`.

Solução: 

$$
\begin{aligned}
\text{funA } [2, 3, 5, 1] &= 2^2 + (\text{funA } [3, 5, 1]) \\
&= 2^2 + (3^2 + (\text{funA } [5, 1])) \\
&= 2^2 + (3^2 + (5^2 + (\text{funA } [1]))) \\
&= 2^2 + (3^2 + (5^2 + (1^2 + (\text{funA } []))))
\end{aligned}
$$

$$
\begin{aligned}
&= 2^2 + 3^2 + 5^2 + 1^2 + 0 \\
&= 4 + 9 + 25 + 1 + 0 \\
&= 13 + 25 + 1 \\
&= 38 + 1 \\
&= 39
\end{aligned}
$$

### Alinha b) 
Considere seguinte definição: 
```hs 
funB :: [Int]-> [Int]
funB [] = [] 
funB (h:t) = if (mod h 2)==0 then h : (funB t) 
								else (funB t) 
```
Diga, justificando, qual é o valor de `funB [8,5,12]`.

Solução:
$$
\begin{aligned}
\text{funB } [8, 5, 12] &= 8 : (\text{funB } [5, 12]) && \text{-- Como (mod 8 2 == 0) é True, o 8 fica} \\
&= 8 : (\text{funB } [12]) && \text{-- Como (mod 5 2 == 0) é False, o 5 salta fora} \\
&= 8 : 12 : (\text{funB } []) && \text{-- Como (mod 12 2 == 0) é True, o 12 fica} \\
&= 8 : 12 : [] && \text{-- Caso base atingido: funB [] = []}
\end{aligned}
$$
$$
\begin{aligned}
&= 8 : [12] \\
&= [8, 12]
\end{aligned}
$$

### Alinha c)
Considere a seguinte definição:
```hs 
funC (x:y:t) = funC t 
funC [x] = [x] 
funC [] = []
```
Diga, justificando, qual é o valor de `funC [1,2,3,4,5]`.

Solução:
$$
\begin{aligned}
\text{funC } [1, 2, 3, 4, 5] &= \text{funC } [3, 4, 5] && \text{-- O 1 (x) e o 2 (y) são ignorados; t = [3,4,5]} \\
&= \text{funC } [5] && \text{-- O 3 (x) e o 4 (y) são ignorados; t = [5]} \\
&= [5] && \text{-- Caso base atingido: funC [x] = [x], onde x = 5}
\end{aligned}
$$

### Alinha d) 
Considere a seguinte definição:
```hs
funD l = g [] l 
g acc [] = acc 
g acc (h:t) = g (h:acc) t 
```
Diga, justificando, qual ´e o valor de `funD "otrec"`.

Solução:
$$
\begin{aligned}
\text{funD } \text{"otrec"} &= \text{g } \text{[] } \text{"otrec"} \\
&= \text{g } \text{['o'] } \text{"trec"} && \text{-- O 'o' sai da lista e entra no acc} \\
&= \text{g } \text{['t', 'o'] } \text{"rec"} && \text{-- O 't' entra à frente do 'o'} \\
&= \text{g } \text{['r', 't', 'o'] } \text{"ec"} \\
&= \text{g } \text{['e', 'r', 't', 'o'] } \text{"c"} \\
&= \text{g } \text{['c', 'e', 'r', 't', 'o'] } \text{[]} && \text{-- Lista original vazia!} \\
&= \text{['c', 'e', 'r', 't', 'o']} && \text{-- Caso base atingido: g acc [] = acc}
\end{aligned}
$$

## Exercício 2
Defina recursivamente as seguintes funções sobre listas:

### Alinha a)
`dobros :: [Float]-> [Float]` que recebe uma lista e produz a lista em que cada elemento é o dobro do valor correspondente na lista de entrada.

```hs title:dobros
dobros :: [Float] -> [Float] 
dobros [] = []
dobros (x:xs) = 2*x : (dobros xs)
```

```hs title:numOcorre
numOcorre :: Char -> String -> Int

numOcorre x (c:cs) = if x == c
```

```hs title:positivos
positivos [x] = x > 0 
positivos (x:xs) | x < 0 = False
                 | otherwise = positivos xs
```

### Alinha h)
`nosPrimeiros :: (Eq a) => a-> [(a,b)]-> Bool` que testa se um elemento aparece na lista como primeira componente de algum dos pares.

> Se a lista for vazia então dá False

```hs title:nosPrimeiros
nosPrimeiros :: (Eq a) => a -> [(a, b)] -> Bool
nosPrimeiros a [] = False
nosPrimeiros a (x:xs) | a == fst x = True
                      | a /= fst x =  nosPrimeiros a xs
                      | otherwise = False
```

### Alinha i)
`sumTriplos :: (Num a, Num b, Num c) => [(a,b,c)]-> (a,b,c)`soma uma lista de triplos componente a componente. 
Por exemplo, `sumTriplos [(2,4,11), (3,1,-5), (10,-3,6)] = (15,2,12)`.

```hs title:sumTriplos
sumTriplos :: (Num a, Num b, Num c) => [(a,b,c)] -> (a,b,c)
sumTriplos [] = (0,0,0)
sumTriplos ((x,y,z):t) = (x + x', y + y', z + z')
                   where (x', y', z') = sumTriplos t
```

## Exercício 3
Recorrendo a funções do módulo `Data.Char`, defina recursivamente as seguintes funções sobre strings. 

### Alinha a)
`soDigitos :: [Char]-> [Char]`que recebe uma lista de caracteres, e seleciona dessa lista os caracteres que são algarismos.

```hs title:soDigitos
soDigitos :: [Char] -> [Char]
soDigitos [] = []
soDigitos (h:t) | not (isNumber h) = soDigitos t
                | isNumber h = h : soDigitos t
```

```hs title:minusculas
minusculas :: [Char] -> Int
minusculas [] = 0
minusculas (h:t) = if not(isNumber h) &&  not (isUpperCase h) 
                   then 1 + minusculas t
                   else minusculas t
```

## Exercício 4
Uma forma de representar polinómios de uma variável é usar listas de monômios representados por pares (coeficiente, expoente) 
`type Polinomio = [Monomio] type Monomio = (Float,Int)` 
Por exemplo, `[(2,3), (3,4), (5,3), (4,5)]` representa o polinómio $2x^3 + 3x^4 + 5x^3 + 4x^5$. 

Defina as seguintes funções:

### Alinha a)
`conta :: Int-> Polinomio-> Int` de forma a que (conta n p) indica quantos monômios de grau n existem em p.

```hs title:conta
conta :: Int -> Polinomio -> Int
conta n ((x,y):t) = if n == y
                    then 1 + conta n t
                    else conta n t
```

### Alinha b)
`grau :: Polinomio-> Int` que indica o grau de um polinómio.

```hs title:grau
grau :: Polinomio -> Int
grau [(a,b)] = b
grau ((a,b):t)  = if b > g 
                  then b
                  else g
            where g = grau t 
```

### Alinha c)
`selgrau :: Int-> Polinomio-> Polinomio` que seleciona os monômios com um dado grau de um polinómio.

```hs title:selgrau
selgrau :: Int -> Polinomio -> Polinomio
selgrau g [] = []
selgrau g ((a,b):t) = if g == b 
                      then (a,b) : l 
                      else l
      where l = selgrau g t
```

### Alinha d) 
`deriv :: Polinomio-> Polinomio` que calcula a derivada de um polinómio.

```hs title:deriv
deriv :: Polinomio -> Polinomio
deriv [] = []
deriv ((a,b):t) = if b > 0 
                  then (a * (fromIntegral b), b-1): l
                  else ((a,b):l)
      where l = deriv t
```

### Alinha e)
`calcula :: Float-> Polinomio-> Float`que calcula o valor de um polinómio para uma dado valor de x.

```hs title:calcula
calcula :: Float -> Polinomio -> Float
calcula x [(a,b)] = a * (x^ b) 
calcula x ((a,b):t) = a * (x^ b) + soma
      where soma = calcula x t
```

### Alinha f)
`simp :: Polinomio-> Polinomio` que retira de um polinómio os monômios de coeficiente zero.

```hs title:
simp :: Polinomio -> Polinomio
sim [] = []
simp ((a,b):t) = if a == 0 
                 then simp t
                 else (a,b): simp t      
```

### Alinha g)
`mult :: Monomio-> Polinomio-> Polinomio` que calcula o resultado da multiplicação de um monômio por um polinómio.

```hs title:mult
mult :: Monomio -> Polinomio -> Polinomio
mult (c,e) [] = [] 
mult (c,e) ((a,b):t) = (a*c, b + e): resto
      where resto = mult (c,e) t
```

### Alinha h)
`normaliza :: Polinomio-> Polinomio` que dado um polinómio constrói um polinómio equivalente em que não podem aparecer vários monômios com o mesmo grau.

> Para que não haja monômios com o mesmo grau, o que a função faz 
é somar os coeficientes dos monômios de mesmo grau.

- Função Principal
```hs title: normaliza
normaliza :: Polinomio -> Polinomio
normaliza [] = []
normaliza ((a,b):t) = if l == []
                      then (a,b): normaliza t
                      else (a + sumMonomios l, b): normaliza (deleteMonomio l t)

      where l = selgrau b t 
```

- Função Auxiliar que soma monômios
```hs title:sumMonomios
sumMonomios :: [Monomio] -> Float
sumMonomios [] = 0
sumMonomios ((a,b):t) = a + sumMonomios t
```

- Função Auxiliar que elimina os elementos que estão no primeirto polinomio do segundo polinomio
```hs title:deleteMonomio
deleteMonomio :: Polinomio -> Polinomio  -> Polinomio
deleteMonomio p1 [] = []
deleteMonomio [] p2 = p2
deleteMonomio ((a,b):t) ((c,d):r) = if a == c && b == d 
                            then deleteMonomio  t r
                            else (c,d) : deleteMonomio ((a,b):t) r
```

### Alinha i)
`soma :: Polinomio-> Polinomio-> Polinomio` que soma dois polinómios de forma a que se os polinómios que recebe estiverem normalizados produz também um polinómio normalizado.

```hs title:soma
soma :: Polinomio -> Polinomio -> Polinomio
soma p1 [] = p1
soma [] p2 = p2
soma p1 p2 = normaliza p3 
       where p3 = p1++p2
```

### Alinha j)
`produto :: Polinomio-> Polinomio-> Polinomio` que calcula o produto de dois polinómios.

```hs title:produto
produto :: Polinomio -> Polinomio -> Polinomio
produto [] p2 = []
produto p1 [] = p1
produto ((a,b):t) ((c,d):r) =  normaliza (mult (a,b) ((c,d):r) ++ produto t ((c,d):r))
```

### Alinha k)
`ordena :: Polinomio-> Polinomio` que ordena um polinómio por ordem crescente dos graus dos seus monómios.

```hs title:
ordena :: Polinomio -> Polinomio
ordena [] = []
ordena [x] = [x]
ordena (h:t) = l ++ ordena resto 
      where mg = grau (h:t) 
            l = selgrau mg (h:t)
            resto = deleteMonomio l (h:t)
```

### Alinha l)
`equiv :: Polinomio-> Polinomio-> Bool` que testa se dois polinómios são equivalentes.

```hs title:equiv
equiv :: Polinomio -> Polinomio -> Bool
equiv [] p2 = False
equiv p1 [] = False
equiv p1 p2 = if deleteMonomio p1' p2' == []
             then True 
             else False
          where p1' = normaliza p1 
                p2' = normaliza p2 
```
