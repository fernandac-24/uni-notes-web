## Exercício 1
Assumindo que uma hora é representada por um par de inteiros, uma viagem pode ser representada por uma sequência de etapas, onde cada etapa é representada por um par de horas (partida, chegada): 

`data Hora = H Int Int deriving Show
`type Etapa = (Hora,Hora)`
`type Viagem = [Etapa]`

Por exemplo, se uma viagem for `[(H 9 30, H 10 25), (H 11 20, H 12 45), (H 13 30, H 14 45)]` significa que teve três etapas:
• a primeira começou às 9 e meia e terminou às 10 e 25; 
• a segunda começou às 11 e 20 e terminou à uma menos um quarto; 
• a terceira começou às 1 e meia e terminou às 3 menos um quarto; 

Para este problema, vamos trabalhar apenas com viagens que começam e acabam no mesmo dia. Utilizando as funções sobre horas que definiu na Ficha 1, defina as seguintes funções:

### Alinha a)
Testar se uma etapa está bem construída (i.e., o tempo de chegada é superior ao de partida e as horas são válidas).

- Função Principal
```hs title:etapaValida
etapaValida :: Etapa -> Bool
etapaValida (hp, hc) = if horaValida hp == True && horaValida hc == True && comparaHora hc hp == True 
                           then True
                           else False 
```

- Função Auxiliar que define se uma hora é maior do que a outra
```hs title:comparaHora
comparaHora :: Hora -> Hora -> Bool
comparaHora (H h1 m1) (H h2 m2) | h1 == h2 && m1 > m2 = True
                                | h1 > h2 = True
                                | otherwise = False
```

- Função Auxiliar que define se uma hora é valida
```hs title:horaValida
horaValida :: Hora -> Bool
horaValida (H h m) = if h < 24 && h >= 0 && m < 60 && m >= 0 then True
                    else False 
```

### Alinha b)
Testa se uma viagem está bem construída (i.e., se para cada etapa, o tempo de chegada é superior ao de partida, e se a etapa seguinte começa depois da etapa anterior ter terminado).

```hs title:viagemValida
viagemValida :: Viagem -> Bool
viagemValida []= True -- Se a lista for vazia  
viagemValida [e] = etapaValida (e) 
viagemValida (e1: e2 :t) = if etapaValida (e1)                               &&
                               comparaHora (fst e1) (snd e2)                 && 
                               viagemValida (t)
                          then True
                          else False
```

Utiliza as funções `etapaValida`e `comparaHora` da [[F3#Alinha a)]]

### Alinha c) 
Calcular a hora de partida e de chegada de uma dada viagem.

```hs title:horaPartidaChegada
horaPartidaChegada :: Viagem -> (Hora, Hora)
horaPartidaChegada [e]= (e)
horaPartidaChegada v = ((fst (head v)), (snd (last v)))
```

## Exercício 2
Considere as seguinte definição de um tipo para representar linhas poligonais. 

`type Poligonal = [Ponto]`

O tipo Ponto é idêntico ao definido na Ficha 1( [[Uni/1st/1S/PF/Fichas/F1#Alinha b)]] ). Nas resolução das alíneas seguintes pode utilizar funções definidas nessa ficha.

> [!attention] O exercício era para ser feito com a definição de Ponto da [[Uni/1st/1S/PF/Fichas/F1#Exercício 6]], porém eu o fiz com a definição mais básica da [[Uni/1st/1S/PF/Fichas/F1#Alinha b)]] e apenas a chamei de `Ponto` no lugar de `Ponto'`. 


```hs
type Ponto = (Double, Double)
type Poligonal = [Ponto]
```

### Alinha a)
Defina a função para calcular o comprimento de uma linha poligonal.

```hs title:comprimentoPoligonal
comprimentoPoligonal :: Poligonal -> Double
comprimentoPoligonal [] = 0
comprimentoPoligonal [x] = 0
comprimentoPoligonal (p1:p2:t) = let (x1,y1) = p1
                                     (x2,y2) = p2 
                               in  sqrt( ((x2 - x1)^ 2) + ((y2 - y1)^ 2) ) + comprimentoPoligonal t
```

### Alinha b)
Defina uma função para testar se uma dada linha poligonal é ou não fechada.

```hs title:linhaPoligonalFechada
linhaPoligonalFechada :: Poligonal -> Bool
linhaPoligonalFechada l =  head l == last l 
```

### Alinha c) 
Defina a função `triangula :: Poligonal-> [Figura]` que, dada uma linha poligonal fechada e convexa, calcule uma lista de triângulos cuja soma das áreas seja igual à área delimitada pela linha poligonal. O tipo Figura é idêntico ao definido na Ficha 1 ( [[Uni/1st/1S/PF/Fichas/F1#Exercício 7]] ).

```hs title:triangula
triangula :: Poligonal -> [Figura]
triangula ps | length ps < 4 = []
             | otherwise = triangula' (head ps) (tail ps)
```

```hs title:"Outra versão"
triangula' :: Ponto -> [Ponto] -> [Figura] 
triangula' p1 (p2:p3:resto) | null resto = [Triangulo p1 p2 p3]
                            | otherwise = Triangulo p1 p3 p3 : triangula' p1 (p3:resto)
triangula' _ _ = [] 
```

## Exercício 4
Pretende-se guardar informação sobre os aniversários das pessoas numa tabela que associa o nome de cada pessoa à sua data de nascimento. Para isso, declarou-se a seguinte estrutura de dados:

```hs 
type Dia = Int
type Mes = Int
type Ano = Int

data Data = D Dia Mes Ano

type TabDN = [(Nome,Data)]
```

### Alinha a)
Defina a função `procura :: Nome-> TabDN-> Maybe Data`, que indica a data de nascimento de uma dada pessoa, caso o seu nome exista na tabela.

```hs title:procura
procura :: Nome -> TabDN -> Maybe Data
procura n [] = Nothing
procura n ((n', d):t) = if n == n' 
                        then Just d
                        else procura n t
```

### Alinha b)

```hs title:idade
idade :: Data -> Nome -> TabDN -> Maybe Int
idade _ _ [] = Nothing 
idade (D d m a) n ((n', D d' m' a'):t) = if n == n' 
                                     then Just (a-a'+ m-m' + d-d')
                                     else idade (D d m a) n t
```

### Alinha c)
Defina a função `anterior :: Data-> Data-> Bool`, que testa se uma data é anterior a outra data.

```hs title:anterior
anterior :: Data -> Data -> Bool

                                | a < a' && m < m' = True
                                | a < a' && m < m' && d < d' = True
                                | otherwise = False
```
