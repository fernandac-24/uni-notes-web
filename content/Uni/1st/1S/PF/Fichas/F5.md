# Ficha 5 - Funções de ordem superior

## Exercício 1 
Apresente definições das seguintes funções de ordem superior, já pré-definidas no Prelude
ou no `Data.List`:

### Alinha a) 
`any :: (a -> Bool) -> [a] -> Bool` que teste se um predicado é verdade para
algum elemento de uma lista; por exemplo:
`any odd [1..10] == True`

```hs title:"any' "
any' :: (a -> Bool) -> [a] -> Bool
any' p [] = False
any' p (h:t) = if p h then True
              else any' p t 
```
^code1
### Alinha b)
`zipWith :: (a->b->c) -> [a] -> [b] -> [c]` que combina os elementos de
duas listas usando uma função específica; por exemplo:
`zipWith (+) [1,2,3,4,5] [10,20,30,40] == [11,22,33,44].`

```hs title:zipWith
zipWith' :: (a->b->c) -> [a] -> [b] -> [c]
zipWith' f (x:xs) (y:ys) = f x y : zipWith' f xs ys
zipWith' _ _ _ = []

{- Forma que eu fiz podia ser simplificada 
zipWith' f [] l = []
zipWith' f l [] = []
zipWith' f (x:xs) (y:ys) = f x y : zipWith' f xs ys 
  -}
```
^code2
### Alinha c) 
`takeWhile :: (a->Bool) -> [a] -> [a]` que determina os primeiros elementos
da lista que satisfazem um dado predicado; por exemplo:
`takeWhile odd [1,3,4,5,6,6] == [1,3].`

```hs title:takeWhile'
takeWhile' :: (a->Bool) -> [a] -> [a]
takeWhile' p [] = []
takeWhile' p (h:t) = if p h then h: takeWhile' p t
                     else []
```
^code3

### Alinha d)
`dropWhile :: (a->Bool) -> [a] -> [a]` que elimina os primeiros elementos da
lista que satisfazem um dado predicado; por exemplo:
`dropWhile odd [1,3,4,5,6,6] == [4,5,6,6].`

```hs title:dropWhile
dropWhile' :: (a->Bool) -> [a] -> [a]
dropWhile' p [] = []
dropWhile' p (h:t) = if p h then takeWhile' p t
                     else h:t
```
^code4

### Alinha e) 
`span :: (a-> Bool) -> [a] -> ([a],[a])`, que calcula simultaneamente os dois
resultados anteriores. Note que apesar de poder ser definida à custa das outras
duas, usando a definição.

`span p l = (takeWhile p l, dropWhile p l)`

nessa definição há trabalho redundante que pode ser evitado. Apresente uma
definição alternativa onde não haja duplicação de trabalho.

```hs title:span
span' :: (a-> Bool) -> [a] -> ([a],[a])
span' p [] = ([], [])
span' p l = (takeWhile' p l, dropWhile' p l)
```
^code5
_Usando as outras duas funções: [[#^code3|takeWhile']] and [[#^code4|dropWhile']]. Estamos a percorrer duas vezes a lista. Mas o que o enunciado quer é uma função que evite trabaçho redudante. _

```hs title:'span otimizada' 
span' :: (a-> Bool) -> [a] -> ([a],[a])
span' p [] = ([],[])
span' p (h:t) = if p h then (h:take, drop)
                       else ([], h:t)
              where (take,drop) = span' p t
```
^code6

### Alinha f)
`deleteBy :: (a -> a -> Bool) -> a -> [a] -> [a]`que apaga o primeiro elemento de uma lista que é “igual” a um dado elemento de acordo com a função
de comparação que é passada como parâmetro. Por exemplo:
`deleteBy (\x y -> snd x == snd y) (1,2) [(3,3),(2,2),(4,2)]`

```hs title:deleteBy
deleteBy' :: (a -> a -> Bool) -> a -> [a] -> [a]
deleteBy' f a [] = []
deleteBy' f a (h:t) = if f a h then deleteBy' f a t
                    else h: deleteBy' f a t
```
^code7

### Alinha g) 
`sortOn :: Ord b => (a -> b) -> [a] -> [a]` que ordena uma lista comparando os resultados de aplicar uma função de extracção de uma chave a cada elemento de uma lista. Por exemplo:
`sortOn fst [(3,1),(1,2),(2,5)] == [(1,2),(2,5),(3,1)].`

```hs title:sortOn
sortOn' :: Ord b => (a -> b) -> [a] -> [a]
sortOn' _ [] = []
sortOn' f (h:t) = insere f h (sortOn' f t)
```
^code8

```hs title:'auxilar insere'
insere :: Ord b => (a -> b) -> a -> [a] -> [a]
insere _ e [] = [e]
insere f e (h:t) | f e <= f h = e:h:t
                 | otherwise = h:insere f e t
```


## Exercício 2
Relembre a questão sobre polinómios introduzida na Ficha 3, onde um polinómio era
representado por uma lista de monómios representados por pares (coeficiente, expoente)

```hs 
type Polinomio = [Monomio]
type Monomio = (Float,Int)
```

Por exemplo, [(2,3), (3,4), (5,3), (4,5)] representa o polinómio $2x3 + 3x^4 +
5x^3 + 4x^5$ . Redefina as funções pedidas nessa ficha, usando agora funções de ordem
superior (definidas no Prelude ou no Data.List) em vez de recursividade explı́cita:

### Alinha a)
`selgrau :: Int -> Polinomio -> Polinomio` que selecciona os monómios com
um dado grau de um polinómio.

```hs title:selgrau
selgrau' :: Int-> Polinomio-> Polinomio
selgrau' x l = filter (\m -> snd m == x) l
```

> [!info] The filter fuction
> Takes a predicate function `(a -> Bool)` and a list `[a]`, returning a new list containing only the elements that satisfy the predicate.
> Is predifined in standard Haskell. 

### Alinha b)
`conta :: Int -> Polinomio -> Int` de forma a que (conta n p) indica quan-
tos monómios de grau n existem em p.

```hs title:conta
conta' :: Int-> Polinomio-> Int
conta' x p = length (selgrau' x p)
```

> [!info] The length fuction 
> Returns the total number of elements in a list. (Predifined)

### Alinha c)
`grau :: Polinomio -> Int` que indica o grau de um polinómio.

```hs title:grau
grau :: Polinomio-> Int 
grau p = maximum (map (\m -> snd m) p) 
```

> [!info] The map fuction
> applies a given function to every element in a list. (Predifined)

> [!info] The maximum fuction 
> finds and returns the highest element in a non-empty list. (Predifined)

### Alinha d)
`deriv :: Polinomio -> Polinomio` que calcula a derivada de um polinómio.

```hs title:'deriv polinomio'
deriv' :: Polinomio -> Polinomio
deriv' p = filtro
       where lista = map (\(x,y) -> (x* fromIntegral y, y-1)) p 
             filtro = filter (\(a,b) -> b >= 0) lista 
```

### Alinha e)
`calcula :: Float -> Polinomio -> Float` que calcula o valor de um polinómio
para uma dado valor de x.

```hs title:calcula
calcula' :: Float -> Polinomio -> Float
calcula' x p1 = sum (map (\(a,b) -> ((x) ^ b) * a ) p1 )
```

### Alinha f)
`simp :: Polinomio -> Polinomio` que retira de um polinómio os monómios de
coeficiente zero.

```hs title:'simp polinomio'
simp' :: Polinomio -> Polinomio
simp' p1 = case listzero of 
           [] -> p1 
           _ -> novopolg
     where listzero = filter (\(a,b) -> a == 0) p1  
           novopolg = filter (\x -> x `notElem ` listzero ) p1
```

### Alinha g)
`mult :: Monomio -> Polinomio -> Polinomio` que calcula o resultado da mul-
tiplicação de um monómio por um polinómio.

```hs title:'mult monomio * polinomio'
mult :: Monomio -> Polinomio -> Polinomio
mult  (x,y) p1 = ( map (\(a,b) -> (a * x , b + y)) p1 )
```

### Alinha h)
`ordena :: Polinomio -> Polinomio` que ordena um polonómio por ordem crescente dos graus dos seus monómios.

```hs title:'ordena polinomio'
ordena :: Polinomio -> Polinomio
ordena p1 = sortOn' snd p1 
```

> [!info] The snd fuction
> It takes a 2-tuple (pair) and returns its **second** element.

### Alinha i)
`normaliza :: Polinomio -> Polinomio` que dado um polinómio constrói um
polinómio equivalente em que não podem aparecer varios monómios com o mesmo
grau.

```hs title:'normaliza polinomio'
normaliza :: Polinomio -> Polinomio
normaliza p1 = map somaGrupos grupos 
     where ordenado = ordena p1 
           grupos = groupBy (\ m n -> snd m == snd n) ordenado 
           -- Função que soma os coeficientes dos monomios de mesmo grau
           -- recebe um único grupo 
           somaGrupos g = (sum (map fst g) , snd (head g))
```

### Alinha j)
`soma :: Polinomio -> Polinomio -> Polinomio` que faz a soma de dois polinómios de forma que se os polinómios que recebe estiverem normalizados produz também um polinómio normalizado.

```hs title:'soma polinomios'
soma :: Polinomio -> Polinomio -> Polinomio 
soma p1 p2 = normaliza listaT 
  where listaT = p1 ++ p2
```

### Alinha k)
`produto :: Polinomio -> Polinomio -> Polinomio` que calcula o produto de
dois polinómios.

```hs title:'produto polinomios'
produto :: Polinomio -> Polinomio -> Polinomio 
produto p1 p2 = normaliza (foldr (\ m acc -> mult m p2 ++ acc) [] p1 )
```

### Alinha l)
`equiv :: Polinomio -> Polinomio -> Bool` que testa se dois polinómios são
equivalentes.

```hs title: equiv
equiv :: Polinomio -> Polinomio -> Bool 
equiv p1 p2 = normaliza p1 == normaliza p2
```

## Exercício 3
Considere a sequinte definição para representar matrizes:
`type Mat a = [[a]]`

Por exemplo, a matriz (triangular superior) $\begin{bmatrix} 1 & 2 & 3 \\ 0 & 4 & 5 \\ 0 & 0 & 6 \end{bmatrix}$ seria representada por `[[1,2,3], [0,4,5], [0,0,6]]`

Defina as seguintes funções sobre matrizes (use, sempre que achar apropriado, funções de ordem superior). 

### Alinha a)
`dimOK :: Mat a -> Bool` que testa se uma matriz está bem construı́da (i.e., se
todas as linhas têm a mesma dimensão).

```hs title:dimOK
dimOK :: Mat a -> Bool 
dimOK [] = False
dimOK m = length (nub (map length m)) == 1 
-- nub = tira os números repetidos numa lista - se forem todos iguais resta uma lista unitária
-- para usa-lá tem que import Data.List
```

### Alinha b)
`dimMat :: Mat a -> (Int,Int)` que calcula a dimensão de uma matriz.

```hs title:dimMat
dimMat :: Mat a -> (Int, Int)
dimMat [] = (0,0)
dimMat (h:t) = (length (h:t), length h)
```

### Alinha c)
`addMat :: Num a => Mat a -> Mat a -> Mat a` que adiciona duas matrizes.

```hs title:addMat
addMat :: Num a => Mat a -> Mat a -> Mat a 
addMat [x] [] = [x]
addMat [] [x] = [x]
addMat (x:xs) (y:ys) = zipWith' (+) x y : addMat xs ys 
addMat _ _ = []
```

### Alinha d)
`transpose :: Mat a -> Mat a` que calcula a transposta de uma matriz.

```hs title:transpose
transpose' :: Mat a -> Mat a
transpose' [] = []
transpose' m = primeiraColuna m : transpose' (removePrimCol m)
```

```hs title:primeiraColuna 
primeiraColuna :: Mat a -> [a]
primeiraColuna [] = []
primeiraColuna (h:t) | null h = []
                     | otherwise = head h : primeiraColuna t
```

```hs title:removePrimCol
removePrimCol :: Mat a -> Mat a
removePrimCol [] = []
removePrimCol (h:t) | null h = []
                    | otherwise = tail h : removePrimCol t
```

### Alinha e)
`multMat :: Num a => Mat a -> Mat a -> Mat a` que calcula o produto de duas matrizes.

```hs title:multMat
multMat' :: Num a => Mat a -> Mat a -> Mat a 
multMat' m1 m2 = map (\linha -> map (prod linha ) m2T ) m1 
      where m2T = transpose' m2 
            -- Função que calcula o produto de uma linha por uma coluna 
            prod l c = sum (zipWith (*) l c )
```

### Alinha f)
`zipWMat :: (a -> b -> c) -> Mat a -> Mat b -> Mat c` que, à semelhança do que acontece com a função `zipWith`, combina duas matrizes. Use essa função para definir uma função que adiciona duas matrizes.

```hs title:zipWMat
zipWMat :: (a -> b -> c) -> Mat a -> Mat b -> Mat c
zipWMat f m1 m2 = zipWith (zipWith (f)) m1 m2 
```

### Alinha g)
`triSup :: Num a => Mat a -> Bool` que testa se uma matriz quadrada é triangular superior (i.e., todos os elementos abaixo da diagonal são nulos).

```hs title:triSup
triSup :: Num a => Mat a -> Bool
triSup m = all (\(i, linha) -> all (==0) (take i linha)) (listaP )
      where listaP = zip [0..] m -- [(0, [linha]), (1, [linha])...]
```

### Alinha h)
rotateLeft :: Mat a -> Mat a que roda uma matriz 90o para a esquerda. Por exemplo, o resultado de rodar a matriz acima apresentada deve corresponder à matriz $\begin{bmatrix} 3 & 5 & 6 \\ 2 & 4 & 0 \\ 1 & 0 & 6 \end{bmatrix}$ .

```hs title:rotateLeft
rotateLeft :: Mat a -> Mat a 
rotateLeft [] = []
rotateLeft m = ultimaCol m : retiraUltCol m
```

```hs title:ultimaCol
ultimaCol :: Mat a -> [a]
ultimaCol [] = []
ultimaCol (h:t) = last h : ultimaCol t 
```

```hs title:retiraUltCol
retiraUltCol :: Mat a -> Mat a 
retiraUltCol [] = []
retiraUltCol (h:t) = init h : retiraUltCol t 
```
