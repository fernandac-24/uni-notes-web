## Exercício 1

Considere o seguinte tipo para representar árvores binárias. 

```hs title:'BTree struct'
data BTree a = Empty
				| Node a (Btree a) (Btree a)
			deriving Show
``` 
^BTreeStruct

Defina as seguintes funções: 

### Alinha a)
`altura :: BTree a -> Int` que calcula a altura da árvore. 
```hs title: 'altura'
altura:: BTreee a -> Int
altura Empty = 0 
altura (Node _ e d) = 1 + max (altura e) (altura d)
``` 
_The `max` fuction is already predifined in Haskell. _

### Alinha b)
`contaNodos :: BTree a -> Int` ˋ que calcula o número de nodos da árvore. 
```hs title:contaNodos
contaNodos :: BTree a -> Int 
contaNodos Empty = 0
contaNodos (Node _ e d) = folhas e + contaNodos e + contaNodos d
```
 
### Alinha c)
`folhas :: BTree a -> Int` que calcula o número de folhas (i.e., nodos sem descendentes ) da árvore. 

```hs title:folhas
folhas :: BTree a -> Int
folhas Empty = 0
folhas (Node _ Empty Empty) = 1
folhas (Node _ e d) = folhas e + folhas d
``` 

### Alinha d)
`prune :: Int -> BTree a -> BTree a`, que remove de uma árvore todos os elementos a partir de uma determinada profundidade.

```hs title:'prune BTree'
prune :: Int -> BTree a -> BTree a
prune _ Empty = Empty
-- prune 0 _ = Empty -- Não é considerado uma poda 
prune 1 (Node x l r) = Node x Empty Empty 
prune n (Node x l r) = Node x (prune (n-1) l) (prune (n-1) r)
```

### Alinha e)
`path :: [Bool] -> BTree a -> [a]`, que dado um caminho (False corresponde a esquerda e True a direita) e uma árvore, dá a lista com a informação dos nodos por onde esse caminho passa.

```hs title:'path BTree'
-- False = Esquerda
-- True = Direita
path :: [Bool] -> BTree a -> [a]
path _ Empty = []
path _ (Node x Empty Empty) = [x]
path (h:t) (Node x l r) | h = x: path t r
                        | not h = x: path t l
```

### Alinha f)
`mirror :: BTree a -> BTree a`, que dá a árvore simétrica.

```hs title:'mirror BTree'
mirror :: BTree a -> BTree a
mirror Empty = Empty
mirror (Node x Empty Empty) = Node x Empty Empty
mirror (Node x l r) = Node x (mirror r) (mirror l)
```

### Alinha g)
`zipWithBT :: (a -> b -> c) -> BTree a -> BTree b -> BTree c` que generaliza a função zipWith para árvores binárias.

```hs title:'zipWithBT BTree'
zipWithBT :: (a -> b -> c) -> BTree a -> BTree b -> BTree c
zipWithBT f (Node x1 l1 r1) (Node x2 l2 r2) = Node (f x1 x2) (zipWithBT f l1 l2) (zipWithBT f r1 r2)  
zipWithBT _ _ _ = Empty 
```

## Exercício 2
Defina as seguintes funções, assumindo agora que as árvores são binárias de procura:

> [!note] Árvores Binárias de Procura
>   A raiz é maior que todo os elemento da subárvore esqueda e menor que todos os elemenentos da subárvore direita.
> Ambos subárvores são ABP(árvores binárias de procura).

### Alinha a)
Defina uma função `minimo :: Ord a => BTree a -> a` que determina o menor elemento de uma árvore binária de procura não vazia.

```hs title:'minimo BTree'
minimo :: Ord a => BTree a -> a
minimo (Node x Empty r) = x
minimo (Node x l r) = minimo l 
``` 

### Alinha b)
Defina uma função `semMinimo :: Ord a => BTree a -> BTree a` que remove o menor elemento de uma árvore binária de procura não vazia.

```hs title:'semMinimo BTree'
semMinimo :: Ord a => BTree a -> BTree a
semMinimo (Node _ Empty r) = r
semMinimo (Node _ l _) = semMinimo l 
```

### Alinha c)
Defina uma função `minSmin :: Ord a => BTree a -> (a,BTree a)` que calcula, com uma única travessia da árvore o resultado das duas funções anteriores.

```hs title:'minSmin BTree'
minSmin ::  Ord a => BTree a-> (a,BTree a)
minSmin (Node x Empty r) = (x, r) 
minSmin (Node x l r) = (min, Node x novoL r)
               where (min, novoL) = minSmin l 
```

### Alinha d)
Defina uma função `remove :: Ord a => a -> BTree a -> BTree a` que remove um elemento de uma árvore binária de procura, usando a função anterior.

```hs title:'remove BTree'
remove :: Ord a => a -> BTree a -> BTree a
remove a (Node x Empty Empty) = Empty
remove a (Node x l r) 
              | a < x = Node x (remove a l) r 
              | a > x = Node x l (remove a r)
              | otherwise = case (l, r) of 
                 (Empty, _) -> r
                 (_, Empty) -> l
                 _ -> Node min tree r
                 where (min, tree) = minSmin (Node x l r)
```

## Exercício 3
Considere agora que guardamos a informação sobre uma turma de alunos na seguinte
estrutura de dados:

```hs
type Aluno = (Numero,Nome,Regime,Classificacao)

type Numero = Int

type Nome = String

data Regime = ORD | TE | MEL deriving Show

data Classificacao = Aprov Int
                    | Rep
                    | Faltou
                deriving Show
type Turma = BTree Aluno-- árvore binária de procura (ordenada por número
```

### Alinha a) 
`inscNum :: Numero -> Turma -> Bool`, que verifica se um aluno, com um dado número, está inscrito.

```hs title:inscNum
inscNum :: Numero-> Turma-> Bool
inscNum x (Empty) = False 
inscNum x (Node a l r) 
    | x == pri a = True 
    | x < pri a = inscNum x l
    | x > pri a = inscNum x r
    | otherwise = False 
```

### Alinha b)
`inscNome :: Nome -> Turma -> Bool`, que verifica se um aluno, com um dado
nome, está inscrito.

```hs title:inscNome
inscNome :: Nome-> Turma-> Bool 
inscNome n Empty = False 
inscNome n turma = let listaT = preorder turma   -- Transforma Árvore em lista de Alunos 
                       nomes = map sec listaT -- Transformar a lista de Alunos  em uma lista de nomes 
                    in n `elem` nomes     
```

```hs title:'preoder'
preorder :: Turma -> [Aluno]
preorder Empty = []
preorder (Node x l r) = [x] ++ preorder l ++ preorder r 
```

### Alinha c)
`trabEst :: Turma -> [(Numero,Nome)]`, que lista o número e nome dos alunos trabalhadores-estudantes (ordenados por número).

```hs title:trabEst
trabEst ::  Turma-> [(Numero,Nome)]
trabEst turma = let turmaT = preorder turma 
                    nomeNum = map pair turmaT 
                in ordena nomeNum 

            where pair :: (Numero,Nome,Regime,Classificacao) -> (Numero,Nome)
                  pair aluno = let a = pri aluno 
                                   b = sec aluno 
                                in (a,b)
                  
                  ordena :: [(Numero,Nome)] -> [(Numero,Nome)]
                  ordena [] = []
                  ordena (h:t) = ordena menores ++ [h] ++ ordena maiores 
                           where menores = [x | x <- t, fst x <= fst h] 
                                 maiores = [x | x <- t, fst x > fst h]
```

### Alinha d)
`nota :: Numero -> Turma -> Maybe Classificacao`, que calcula a classificação
de um aluno (se o aluno não estiver inscrito a função deve retornar Nothing).

```hs title:nota
nota ::  Numero -> Turma -> Maybe Classificacao 
nota nm turma 
     | inscNum nm turma = let aluno = encontraAluno nm turma 
                           in Just (quar aluno )

     | otherwise = Nothing 
     
encontraAluno :: Numero -> Turma -> Aluno 
encontraAluno nm (Node x Empty Empty) = x 
encontraAluno nm (Node x l r) 
        | nm == pri x = x 
        | nm < pri x = encontraAluno nm l 
        | otherwise = encontraAluno nm r 
``` 


### Alinha e)
`percFaltas :: Turma -> Float`, que calcula a percentagem de alunos que faltaram à avaliação.

```hs title:percFaltas
percFaltas :: Turma-> Float
percFaltas turma = let listTurma = preorder turma 
                       numAlunos = fromIntegral (length listTurma)
                       listAfalt = listaFaltaram listTurma
                   in case listAfalt of 
                    [] -> 0
                    _ -> let alunosFaltaram = fromIntegral (length listAfalt)
                         in ((alunosFaltaram / numAlunos) *100)
                         
listaFaltaram :: [Aluno] -> [Aluno]
listaFaltaram [] = []
listaFaltaram (h:t) = case quar h of 
                    Faltou -> h : listaFaltaram t 
                    _ -> listaFaltaram t 
```

### Alinha f)
`mediaAprov :: Turma -> Float`, que calcula a média das notas dos alunos que passaram.

```hs title:mediaAprov
mediaAprov :: Turma -> Float
mediaAprov turma  = let listTurma = preorder turma 
                        listNotas = notas listTurma
                    in case listNotas of 
                        [] -> 0
                        _ -> let numNotas = fromIntegral (length listNotas)
                             in (sum listNotas) / numNotas 

-- 
notas :: [Aluno] -> [Float]
notas [] = []
notas (h:t) = case quar h of 
        Aprov nota -> (fromIntegral nota): notas t 
        _ -> notas t 
```

### Alinha g)
`aprovAv :: Turma -> Float`, que calcula o rácio de alunos aprovados por avaliados. Implemente esta função fazendo apenas uma travessia da árvore.

```hs title:aprovAv
aprovAv ::  Turma -> Float 
aprovAv turma = if avali == 0 then 0 else fromIntegral aprov / fromIntegral avali
     where (aprov, avali) = conta turma 
          
           conta :: Turma -> (Int, Int)
           conta Empty = (0, 0)
           conta (Node (_,_,_,clas) l r) =  (a + aprovL + aprovR, b + avalL + avalR) 
                    where (a,b) = validaclass clas
                          (aprovL, avalL) = conta l
                          (aprovR, avalR) = conta r 

           validaclass :: Classificacao -> (Int, Int)
           validaclass c = case c of 
                Aprov _ -> (1, 1)
                Faltou -> (0,0)
                Rep -> (0,1) 
```
