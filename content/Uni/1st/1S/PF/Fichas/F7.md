## Exercício 1
Considere o seguinte tipo para representar expressões inteiras.

```hs 
data ExpInt = Const Int
             | Simetrico ExpInt
             | Mais ExpInt ExpInt
             | Menos ExpInt ExpInt
             | Mult ExpInt ExpInt
```

Os termos deste tipo ExpInt podem ser vistos como árvores cujas folhas são inteiros e
cujos nodos (não folhas) são operadores.

### Alinha a)
Defina uma função `calcula :: ExpInt -> Int` que, dada uma destas expressões calcula o seu valor.

```hs title:calcula
calcula ::  ExpInt -> Int
calcula (Const x) =  x 
calcula (Simetrico x) = -(calcula x)
calcula (Menos l r) = (calcula l) - (calcula r)
calcula (Mais l r) = (calcula l) + (calcula r)
calcula (Mult l r) = (calcula l) * (calcula r )
```

### Alinha b)
Defina uma função `infixa :: ExpInt -> String` de forma a que infixa (Mais (Const 3) (Menos (Const 2) (Const 5))) dê como resultado "(3 + (2 - 5))".

```hs title:infixa
infixa :: ExpInt-> String
infixa (Const x) = show x 
infixa (Simetrico x ) = "-"++ infixa x  
infixa (Menos l r) = "( " ++ infixa l ++ " - " ++ infixa r ++ " )"
infixa (Mais l r ) = "( " ++ infixa l ++ "  +  " ++ infixa r ++ " )"
infixa (Mult l r) = "( " ++ infixa l ++ "  *  " ++ infixa r ++ " )"
```

### Alinha c)
Defina uma outra função de conversão para strings `posfixa :: ExpInt -> String` de forma a que quando aplicada à expressão acima dê como resultado "3 2 5 - +".

```hs title:posfixa
posfixa :: ExpInt-> String
posfixa (Const x) = show x  
posfixa (Simetrico x) = posfixa x ++ " - "
posfixa (Menos l r) = posfixa l ++" "++ posfixa r ++ " - "
posfixa (Mais l r) = posfixa l ++" "++ posfixa r ++ " + "
posfixa (Mult l r) = posfixa l ++" "++ posfixa r ++ " * "
```

## Exercício 2 
Considere o seguinte tipo para representar árvores irregulares (rose trees).

`data RTree a = R a [RTree a]  deriving (Show, Eq)`

Defina as seguintes funções sobre estas árvores:

### Alinha a)
`soma :: Num a => RTree a -> a` que soma os elementos da árvore.

```hs title:'soma RTree'
soma :: Num a => RTree a-> a
soma (R a []) =  a 
soma (R a l) = a + somaL l  
      where somaL :: Num a => [RTree a] -> a 
            somaL [R x []] = x
            somaL ((R x l):t) = x + somaL l 
```

### Alinha b)
`altura :: RTree a -> Int` que calcula a altura da árvore.

```hs title:'altura RTree'
altura ::  RTree a -> Int
altura (R _ []) = 1
altura (R _ l) = 1 + alturaL l 
    where alturaL :: [RTree a] -> Int  
          alturaL [] = 0
          alturaL ((R _ ls):t) = 1 + alturaL ls 
```

### Alinha c)
`prune :: Int -> RTree a -> RTree a` que remove de uma árvore todos os elementos a partir de uma determinada profundidade.

```hs title:'prune RTree'
-- assumindo que o int sempre será válido ou seja pertence ao intervalo [1, altura da arvore ]
prune :: Int -> RTree a -> RTree a  
prune 1 (R a _) = R a []
prune x (R a l) = R a (map (prune (x-1)) l )
```

### Alinha d)
`mirror :: RTree a -> RTree` a que gera a árvore simétrica.

```hs title:'mirror RTree'
mirror ::  RTree a -> RTree a 
mirror (R x l) = let listE = reverse (x: listaElementos l)
                  in constroeTree listE 
        where constroeTree :: [a] -> RTree a
              constroeTree (e:es) = R e (aux es)
                where aux [] = []
                      aux (e:es) = [R e (aux es)]
listaElementos :: [RTree a ] -> [a]
listaElementos [R x []] = [x]
listaElementos ((R x l):t) = [x] ++ listaElementos l 
```

### Alinha e) 
`postorder :: RTree a -> [a]` que corresponde à travessia postorder da árvore.

```hs title:'postorder RTree'
postorder :: RTree a-> [a]
postorder (R x l) = let lista =  listaElementos l 
                     in lista ++ [x]
```

## Exercício 3
Relembre a definição de árvores binárias apresentada na ficha anterior ([[F6#^BTreeStruct | BTree Struct]] ).

Nestas árvores a informação está nos nodos (as extermidades da árvore têm apenas uma marca – Empty). É também habitual definirem-se árvores em que a informação está apenas nas extermidades (leaf trees):

`data LTree a = Tip a | Fork (LTree a) (LTree a)`

Defina sobre este tipo as seguintes funções

### Alinha a)
`ltSum :: Num a => LTree a -> a` que soma as folhas de uma árvore.

```hs title:ltSum
ltSum :: Num a => LTree a-> a   
ltSum (Tip x) = x 
ltSum (Fork l r) = ltSum l + ltSum r  
```

### Alinha b)
`listaLT :: LTree a -> [a]` que lista as folhas de uma árvore (da esquerda para a direita).

```hs title:listaLT
listaLT :: LTree a-> [a]
listaLT (Tip x) = [x]
listaLT (Fork l r) =  listaLT l ++ listaLT r 
```

### Alinha c) 
`ltHeight :: LTree a -> Int` que calcula a altura de uma árvore.

```hs title:ltHeight
ltHeight :: LTree a-> Int
ltHeight (Tip _) = 1
ltHeight (Fork l r) = max hr hl 
              where hr = 1 + ltHeight l
                    hl = 1 + ltHeight r
```

## Exercício 4
Estes dois conceitos podem ser agrupados num só, definindo o seguinte tipo:

```hs 
data FTree a b = Leaf b 
                | No a (FTree a b) (FTree a b)
```

São as chamadas full trees onde a informação está não só nos nodos, como também nas
folhas (note que o tipo da informação nos nodos e nas folhas não tem que ser o mesmo).

### Alinha a)
Defina a função `splitFTree :: FTree a b -> (BTree a, LTree b)` que separa uma árvore com informação nos nodos e nas folhas em duas árvores de tipos diferentes.

```hs title:splitFTree
splitFTree :: FTree a b-> (BTree a, LTree b)
splitFTree (Leaf b) = (Empty, Tip b)
splitFTree (No a l r) = (Node a spBL spBR, Fork spLl spLR)
            where (spBL, spLl) = splitFTree l
                  (spBR, spLR) = splitFTree r
```

### Alinha b)
Defina ainda a função `joinTrees :: BTree a -> LTree b -> Maybe (FTree a b)` que sempre que as árvores sejam compatı́veis as junta numa só.

Para serem incompatíveis têm : 
 1. Onde uma tem um Node a outra tem que ter um Fork 
 2. Onde uma tem um Empty a outra tem que ter um Tip 

```hs title:joinTrees
joinTrees :: BTree a-> LTree b-> Maybe (FTree a b)
joinTrees Empty (Tip b) = Just (Leaf b)
joinTrees (Node a l1 r1) (Fork l2 r2) = 
    case (joinTrees l1 l2, joinTrees r1 r2) of
        (Just fL, Just fR) -> Just (No a fL fR)
        _ -> Nothing 
-- Caso 3: As estruturas são diferentes
joinTrees _ _ = Nothing
```
