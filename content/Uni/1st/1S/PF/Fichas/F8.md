## Exercício 1  

Considere o seguinte tipo de dados para representar fracções

`data Frac = F Integer Integer`

### Alinha a)
Defina a função `normaliza :: Frac -> Frac`, que dada uma fracção calcula uma fracção equivalente, irredutı́vel, e com o denominador positivo. Por exemplo, normaliza (F (-33) (-51)) deve retornar F 11 17 e normaliza (F 50 (-5)) deve retornar F (-10) 1. Sugere-se que comece por definir primeiro a função `mdc :: Integer -> Integer -> Integer` que calcula o máximo divisor comum entre dois números, baseada na seguinte propriedade (atribuida a Euclides):
mdc x y == mdc (x+y) y == mdc x (y+x)

```hs title:mdc
mdc :: Integer -> Integer -> Integer
mdc x y 
    | y == 0 = x 
    | x == y    = x            
    | x > y     = mdc (x - y) y 
    | otherwise = mdc x (y - x) 
```

```hs title:normaliza
normaliza :: Frac-> Frac 
normaliza (F x y) = let divisor = mdc (abs x)  (abs y) 
                     in F (x`div` divisor) (y `div` divisor)
```

igualdadeFrac :: Frac -> Frac -> Bool
igualdadeFrac f1 f2 = let (F x y) = normaliza f1

                     in x == a && y == b

### Alinha e)
Defina **Frac** como instância da classe **Num**. Relembre que a classe Num tem a seguinte definição:

> [!note]- Definição classe Num
> ```hs 
> class (Eq a, Show a) => Num a where 
> 	(+), (*), (-) :: a -> a -> a
> 	negate, abs, signum :: a -> a	
> 	fromInteger :: Integer -> a
> ```

```hs 
instance Num Frac where 
    (+) = maisFrac
    (-) = menosFrac
    (*) = multFrac
    abs = absFrac
    signum = signumFrac
    fromInteger = fromIntegerFrac
```

```hs title:maisFrac
maisFrac :: Frac -> Frac -> Frac 
maisFrac (F x y) (F a b) 
        | y == b = F (x+a) y 
        | otherwise = F ((x*b) + (y*a)) (y*b)
```

```hs title:menosFrac
menosFrac :: Frac -> Frac -> Frac
menosFrac (F x y) (F a b) 
           | y == b = F (x-a) (y)
           | otherwise = F ((x*b) - (y*a)) (y*a) 
```

```hs title:multFrac
multFrac :: Frac -> Frac -> Frac
multFrac (F x y) (F a b) = F (x*a) (y*b)
```

```hs title:absFrac
absFrac :: Frac -> Frac
absFrac (F x y) 
          | x <= 0 && y > 0 = F (-x) y
          | x >= 0 && y < 0 = F x (-y)
          | otherwise = F x y
```

```hs title:signumFrac
signumFrac :: Frac -> Frac 
signumFrac (F x y) 
          | x >= 0 && y > 0 = F 1 1
          | x <= 0 && y < 0 = F 1 1
          | x == 0 = F 0 x 
          | otherwise = F (-1) 1 
```

```hs title:fromIntegerFrac
fromIntegerFrac :: Integer -> Frac 
fromIntegerFrac x = F x 1 
```

Defina a função `ordena :: Extracto -> Extracto`, que transforma um extracto de modo a que a lista de movimentos apareça ordenada por ordem crescente de data.

```hs title:ordena
ordena :: Extracto-> Extracto
ordena (Ext x l) = Ext x (ordenaL l)
                 where ordenaL :: [(Data, String, Movimento)] -> [(Data, String, Movimento)]
                       ordenaL (h:t) = ordenaL maisantigos ++ [h] ++ ordenaL maisnovos
                                where maisantigos = [e | e <- t, pri e >= pri h]
                                      maisnovos = [e | e <- t, pri e < pri h]
                                      pri :: (Data, String, Movimento) -> Data 
                                      pri (d,_, _) = d
```
