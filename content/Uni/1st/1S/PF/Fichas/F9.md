## Exercício 1 
A classe **Random** da biblioteca System. Random agrupa os tipos para os quais é possı́vel gerar valores aleatórios. Algumas das funções declaradas nesta classe são:
* `randomIO :: Random a => IO` a que gera um valor aleatório do tipo a;
* `randomRIO :: Random a => (a,a) -> IO` a que gera um valor aleatório do tipo
a dentro de uma determinada gama de valores.

Usando estas funções implemente os seguintes programas:

### Alinha a)
`bingo :: IO ()` que sorteia os números para o jogo do bingo. Sempre que uma tecla é pressionada é apresentado um número aleatório entre 1 e 90. Obviamente, não podem ser apresentados números repetidos e o programa termina depois de gerados os 90 números diferentes.

```hs 
bingo :: IO ()
bingo = do putStrLn "Bingo!" 
           l <- valores  [] 
           putStr (show l)


                
valores :: [Int] -> IO [Int]
valores l | length l == 90 = return l
          | otherwise = do n <- randomRIO (1,90) 
                        if n elem l 
                        then valores l 
                        else do putStrLn(show n)  valores (n:l) 

-- Outra forma de definir a função bingo, mais eficaz 
-- cria uma lista de 1 a 90 
-- sorteia a posição na lista, e retira a posição na lista
-- diminui o intervalo para o índice pois retira um elemento da lista 
-- e segue até a lista ficar vazia, o que significa que todos os números no intervalo de 1 a 90 foram sorteados 
```

> [!warning] A função `bingo` e sua auxiliar `valores`estavam todas como comentário, é possível que não funcione por causa de algum erro. 

## Exercício 2
Uma aposta do EuroMilhões corresponde à escolha de 5 Números e 2 Estrelas. Os
Números são inteiros entre 1 e 50. As Estrelas são inteiros entre 1 e 9. Para modelar
uma aposta destas definiu-se o seguinte tipo de dados:

`data Aposta = Ap [Int] (Int,Int)`

### Alinha a)
Defina a função `valida :: Aposta -> Bool` que testa se uma dada aposta é válida (i.e. tem os 5 números e 2 estrelas, dentro dos valores aceites e não tem repetições).

```hs title:valida
valida :: Aposta-> Bool 
valida (Ap num (e1,e2)) = length num == 5 && all intervalo num && intervalo' e1 && intervalo' e2
                      where intervalo :: Int -> Bool 
                            intervalo x = x >= 1 && x <= 50
                            intervalo' :: Int -> Bool 
                            intervalo' x = x >= 1 && x <= 9
```

### Alinha b)
Defina a função `comuns :: Aposta -> Aposta -> (Int,Int)` que dada uma aposta
e uma chave, calcula quantos números e quantas estrelas existem em comum nas
duas apostas.

```hs title:comuns
comuns :: Aposta -> Aposta -> (Int, Int)
comuns (Ap num (e1,e2)) (Ap num1 (e3, e4)) = let diferenca = length (num \\ num1) 
                                                in if e1 == e3 && e2 == e4  then (5-diferenca, 2)
                                                   else if e1 /= e3 && e2 /= e4 then (5-diferenca, 0)
                                                   else (5-diferenca, 1)
```

joga :: Aposta-> IO ()

                let res = comuns chave aposta
